
To set up a Unified Kernel Image (UKI) on Chimera Linux,
you can combine Chimera's default initramfs-tools (or dracut) with systemd-boot-ukify.

A UKI packs your kernel, initramfs, cmdline, and microcode into a single .efi file
that can be booted directly by your UEFI firmware or systemd-boot.

1. Install Necessary Tools
	Chimera provides the ukify binary inside the 'systemd-boot-ukify' package.
	You will also need 'llvm' for object copying utilities if you build manually.

	doas apk add systemd-boot-ukify llvm

2. Gather Component Paths To assemble the image,
	locate the files generated by Chimera's kernel updates
	- Kernel:		/boot/vmlinuz-<version>
	- Initramfs:	/boot/initrd.img-<version> (built by initramfs-tools or dracut)
	- Stub Loader:	/usr/lib/systemd/boot/efi/linuxx64.efi.stub

3. Generate the UKI (Manual Method)
	Create a text file containing your kernel parameters (e.g., /etc/kernel/cmdline)
	
	root=UUID=your-root-uuid-here rw loglevel=4

Run ukify to combine everything into a .efi application placed directly
in your EFI System Partition (ESP):

	ukify build \
		--linux=/boot/vmlinuz-YOUR_VERSION \
		--initrd=/boot/initrd.img-YOUR_VERSION \
		--cmdline=@/etc/kernel/cmdline \
		--os-release=@/etc/os-release \
		--stub=/usr/lib/systemd/boot/efi/linuxx64.efi.stub \
		--output=/boot/EFI/Linux/chimera-linux.efi

4. Setting up Automatic Generation
	To avoid doing this manually on every kernel upgrade, Chimera uses standard kernel hooks.
	You can place a script inside

		/etc/kernel/post-install.d/

	to run ukify automatically.

	Create a script named '/etc/kernel/post-install.d/99-uki.sh'
	
	#!/bin/sh

	VERSION="$1"
	KERNEL_IMAGE="$2"
	# Ensure the destination directory exists on your ESP
	mkdir -p /boot/EFI/Linux
	ukify build \
		--linux="$KERNEL_IMAGE" \
		--initrd="/boot/initrd.img-$VERSION" \
		--cmdline=@/etc/kernel/cmdline \
		--os-release=@/etc/os-release \
		--stub=/usr/lib/systemd/boot/efi/linuxx64.efi.stub \
		--output="/boot/EFI/Linux/chimera-$VERSION.efi"

Make the script executable:

	doas chmod +x /etc/kernel/post-install.d/99-uki.sh

5. Secure Boot Signing (Optional)

	If you are using a tool like sbctl to enforce Secure Boot on Chimera
	Generate your custom keys via sbctl create-keys.
	Append the signing keys to your ukify command line

	--secureboot-private-key=/usr/share/secureboot/keys/db/db.key \
	--secureboot-certificate=/usr/share/secureboot/keys/db/db.crt
